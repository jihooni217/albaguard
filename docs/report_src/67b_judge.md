- **18장 손유호를 "시장 · 마케팅 · 검증"으로, 1.2에 링크 전파 추가** (검토자 2 · 7번): 발표 전날 새벽에 팀원 역할을 늘리는 일이라 팀 동의가 먼저다. 13번(2장과 같은 이름)과도 충돌한다.
- **6장 차별점 3 꼬리표 "지어낸 기록이 아니다"** (검토자 3 · 6번 원문): 19장 노트가 "거짓 기록은 막을 수 없다고 인정"하므로 과장이다. "나중에 고친 기록이 아니다"로 바꿔 10번에 넣었다.
- **12장 4행 남은 일을 "매달 넣는지 사용자 검증"으로** (검토자 2 · 3번 원문): 같은 제안의 검토자 3 문장("가설 1" 꼬리표)이 16장 표와 1:1로 이어져 그쪽을 택했다.
- **10장 QR과 "여러분 폰으로" 본문 변경, 2장 "오늘 순서"의 괄호** (검토자 6 · 1·7번): ④ 1번의 조건이 맞을 때만. 조건 확인 전에는 화면에 넣지 않는다.
- **11장 단계 띠와 "배포된 앱을 10/26에 녹화" 자막** (검토자 4 · 1번 본문 부분): 영상 오른쪽에 단계 자막이 이미 있다(11장 노트 "오른쪽이 단계 자막"). 검토자 4가 이것을 놓쳤다.
- **13장 "알바생 몫은 따로 집계되지 않는다"** (검토자 5 · 5번 원문): 통계 전체를 확인한 말이 되어 "따로 알 수 없다"로 바꿔 7번에 넣었다.

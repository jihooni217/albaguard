# 알바가드 사용자 인터뷰 · 설문지

중간 발표(10/27) 전에 알바하는 친구 2~3명에게 10분 안팎으로 물어볼 때 쓰는 질문지예요.
앞부분(1~3)은 설문처럼 짧게 답을 받고, 뒷부분(4~5)은 앱을 보여 주며 이야기하듯 물어요.

시작하기 전에 말해 둘 것
- "수업 과제로 알바비 관리 앱을 만들고 있어요. 10분 정도 몇 가지만 물어볼게요."
- "이름은 적지 않고, 답한 내용은 발표 자료에 '알바생 A' 같은 식으로만 들어가요."
- 녹음하려면 먼저 물어보고, 싫다고 하면 메모만 해요.

답한 사람: 알바생 (  ) · 날짜: 2026년 10월 (  )일 · 물어본 사람: (  )

---

## 1. 기본 (설문)

1. 어떤 알바를 하나요? (카페 / 편의점 / 음식점 / 학원 / 그 밖: ______)
2. 한 주에 몇 시간쯤 일하나요? (  )시간
3. 시급은 얼마인가요? (  )원 · 주휴수당을 받고 있나요? (받음 / 안 받음 / 모름)
4. 근로계약서를 썼나요? (썼고 사본 있음 / 썼지만 사본 없음 / 안 씀)
5. 급여는 어떻게 확인하나요? (통장 입금액만 봄 / 직접 계산해 봄 / 사장님이 주는 명세서 / 확인 안 함)

## 2. 겪은 일 (설문)

6. 받아야 할 돈보다 적게 받은 것 같았던 적이 있나요? (있음 / 없음 / 잘 모르겠음)
7. 있었다면 어떻게 했나요? (사장님께 말함 / 말 못 하고 넘어감 / 친구나 가족과 상의 / 신고를 알아봄)
8. 말 못 하고 넘어갔다면 가장 큰 이유는? (계산이 확실하지 않아서 / 기록이 없어서 / 사장님과 관계가 불편해질까 봐 / 금액이 작아서 / 그 밖: ______)
9. 출퇴근 시간을 어딘가에 기록하나요? (안 함 / 메모장·카톡 / 달력 / 알바 앱: ______)

## 3. 지금 쓰는 것 (설문)

10. 알바비 계산이나 기록에 써 본 앱이 있나요? (없음 / 하우머치 / 알바천국·알바몬 계산기 / 기그 / 그 밖: ______)
11. 써 봤다면 왜 계속 안 썼나요, 또는 왜 계속 쓰나요? (한 줄)

## 4. 앱을 보여 준 뒤 (이야기하듯)

보여 줄 순서: 첫 화면(이번 달 받을 돈) → 급여 비교(받은 금액 넣기 → 덜 받은 돈) → 정산 요청(사장님께 보낼 메시지) → 증빙 묶음 PDF → 설정 탭의 기록 등록

12. 이 앱이 뭘 해 주는 앱인지 한 문장으로 말해 본다면?
    (우리가 뜻한 대로 "덜 받은 알바비를 찾아 주는 앱"으로 이해했는지 본다)
13. 가장 쓸모 있어 보이는 기능 하나는? 왜?
14. 반대로 "이건 안 쓸 것 같다"는 기능은? 왜?
15. 사장님께 보낼 메시지 문구를 보고 어떤 느낌이 드나요? (너무 세다 / 적당하다 / 너무 약하다) 실제로 보낼 수 있을 것 같나요?
16. "기록을 남길 때마다 서버에 확인 번호와 등록 시각이 남는다"는 설명을 듣고, 이게 왜 필요한지 이해가 되나요? 설명을 어떻게 바꾸면 더 쉬울까요?
17. 매달 받은 금액을 앱에 직접 넣어야 해요. 귀찮을 것 같나요, 할 만할 것 같나요?
18. 근무 중에만 열리는 미니게임(스도쿠·틀린 그림 찾기·블록 채우기)이 있어요. 알바 중에 열어 볼 것 같나요?
19. 미니게임 화면에만 광고가 붙는다면 괜찮나요? (괜찮다 / 싫다 / 상관없다)
20. 화면이나 색, 아이콘을 보고 든 생각은? (예쁘다 / 평범하다 / 촌스럽다, 이유)

## 5. 마무리

21. 이 앱이 실제로 있다면 쓸 건가요? (쓴다 / 상황이 생기면 쓴다 / 안 쓴다) 이유는?
22. 친구에게 추천한다면 뭐라고 소개할 건가요? (한 문장)
23. 더 있었으면 하는 기능이나 바뀌었으면 하는 점은?

## 발표 자료에 정리하는 법

- 1~3번 설문 답은 표로 모은다(사람 수가 2~3명이라 "3명 중 2명"처럼 쓰고, %는 쓰지 않는다)
- 4~5번은 인용 한두 줄과 "그래서 무엇을 고쳤다/고칠 계획이다"로 잇는다
- "정식 조사가 아니라 주변 알바생 N명에게 물은 것"이라고 꼭 적는다

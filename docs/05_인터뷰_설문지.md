# 알바가드 사용자 인터뷰 · 설문지

중간 발표(10/27) 전에 주변 친구 2~3명에게 10분 안팎으로 물어볼 때 쓰는 질문지예요.
지금 알바를 하는 사람, 예전에 한 사람, 한 번도 안 한 사람 모두에게 쓸 수 있어요. 맨 앞 질문으로 갈라서 해당하는 부분만 물어요.
앞부분은 설문처럼 짧게 답을 받고, 뒷부분은 앱을 보여 주며 이야기하듯 물어요.

시작하기 전에 말해 둘 것
- "수업 과제로 알바비 관리 앱을 만들고 있어요. 10분 정도 몇 가지만 물어볼게요."
- "이름은 적지 않고, 답한 내용은 발표 자료에 '알바생 A' 같은 식으로만 들어가요."
- 녹음하려면 먼저 물어보고, 싫다고 하면 메모만 해요.

## 0. 먼저 가르기

A. 지금 알바를 하고 있다 → 1·2·3·4·5 모두
B. 지금은 안 하지만 예전에 했다 → 1·2·3·4·5 모두 (예전 알바 기준으로 답하면 돼요)
C. 알바를 한 적이 없다 → 2-2·3·4·5만 (앱을 보여 주고 생각을 들어요)

## 1. 기본 (A·B)

1. 어떤 알바를 하나요(했나요)? (카페 / 편의점 / 음식점 / 학원 / 그 밖: ______)
2. 한 주에 몇 시간쯤 일하나요(했나요)? (  )시간
3. 시급은 얼마인가요(였나요)? (  )원 · 주휴수당을 받고 있나요(받았나요)? (받음 / 안 받음 / 모름)
4. 근로계약서를 썼나요? (썼고 사본 있음 / 썼지만 사본 없음 / 안 씀)
5. 급여는 어떻게 확인하나요(했나요)? (통장 입금액만 봄 / 직접 계산해 봄 / 사장님이 주는 명세서 / 확인 안 함)
6. 출퇴근 시간을 어딘가에 기록하나요(했나요)? (안 함 / 메모장·카톡 / 달력 / 알바 앱: ______)

## 2-1. 겪은 일 (A·B)

7. 받아야 할 돈보다 적게 받은 것 같았던 적이 있나요? (있음 / 없음 / 잘 모르겠음)
   - "없음"이라도 8번은 물어요. 확인해 본 적이 없어서 모르는 경우가 많아요.
8. 받은 돈이 맞는지 직접 계산해서 확인해 본 적이 있나요? (있음 / 없음) 없다면 왜요?
9. (7번이 "있음"이면) 어떻게 했나요? (사장님께 말함 / 말 못 하고 넘어감 / 친구나 가족과 상의 / 신고를 알아봄)
10. (말 못 하고 넘어갔다면) 가장 큰 이유는? (계산이 확실하지 않아서 / 기록이 없어서 / 사장님과 관계가 불편해질까 봐 / 금액이 작아서 / 그 밖: ______)

## 2-2. 생각 (모두, 특히 덜 받은 적이 없거나 알바를 안 한 사람)

11. 주변에서 알바비를 덜 받았다는 이야기를 들은 적이 있나요? (있음 / 없음) 어떤 경우였나요?
12. 급여날, 생각보다 적은 돈이 들어온다면 어떻게 할 것 같나요? (바로 사장님께 묻는다 / 계산부터 해 본다 / 기록이 없어서 그냥 넘어갈 것 같다 / 모르겠다)
13. 그때 가장 걱정될 것 같은 건? (사장님과 관계 / 내 계산이 맞는지 / 증거가 없는 것 / 신고 절차를 몰라서 / 그 밖: ______)
14. 주휴수당·야간수당을 내가 받을 수 있는지 계산할 자신이 있나요? (있음 / 대충 안다 / 없음)

## 3. 지금 쓰는 것 (모두)

15. 알바비 계산이나 기록에 써 본 앱이 있나요? (없음 / 하우머치 / 알바천국·알바몬 계산기 / 기그 / 그 밖: ______)
16. 써 봤다면 왜 계속 안 썼나요, 또는 왜 계속 쓰나요? (한 줄)

## 4. 앱을 보여 준 뒤 (이야기하듯, 모두)

보여 줄 순서: 첫 화면(이번 달 받을 돈) → 급여 비교(받은 금액 넣기 → 덜 받은 돈) → 정산 요청(사장님께 보낼 메시지) → 증빙 묶음 PDF → 설정 탭의 기록 등록

17. 이 앱이 뭘 해 주는 앱인지 한 문장으로 말해 본다면?
    (우리가 뜻한 대로 "덜 받은 알바비를 찾아 주는 앱"으로 이해했는지 본다)
18. 가장 쓸모 있어 보이는 기능 하나는? 왜?
19. 반대로 "이건 안 쓸 것 같다"는 기능은? 왜?
20. 사장님께 보낼 메시지 문구를 보고 어떤 느낌이 드나요? (너무 세다 / 적당하다 / 너무 약하다) 실제로 보낼 수 있을 것 같나요?
21. "기록을 남길 때마다 서버에 확인 번호와 등록 시각이 남는다"는 설명을 듣고, 이게 왜 필요한지 이해가 되나요? 설명을 어떻게 바꾸면 더 쉬울까요?
22. 매달 받은 금액을 앱에 직접 넣어야 해요. 귀찮을 것 같나요, 할 만할 것 같나요?
23. 쉬는 틈에 하는 미니게임(스도쿠·틀린 그림 찾기·블록 채우기)이 있어요. 출퇴근길이나 손님 없는 시간에 열어 볼 것 같나요?
24. 미니게임 화면에만 광고가 붙는다면 괜찮나요? (괜찮다 / 싫다 / 상관없다)
25. 화면이나 색, 아이콘을 보고 든 생각은? (예쁘다 / 평범하다 / 촌스럽다, 이유)

## 5. 마무리 (모두)

26. 이 앱이 실제로 있다면 쓸 건가요? (지금 쓴다 / 알바를 시작하면 쓴다 / 상황이 생기면 쓴다 / 안 쓴다) 이유는?
27. 친구에게 추천한다면 뭐라고 소개할 건가요? (한 문장)
28. 더 있었으면 하는 기능이나 바뀌었으면 하는 점은?

## 물어본 사람이 끝나고 적을 것

- 답한 사람 구분: A 현재 알바 / B 예전 알바 / C 알바 안 함
- 답한 사람이 가장 오래 멈춰서 본 화면:
- 설명 없이 바로 알아들은 것 / 설명해야 알아들은 것:
- 예상과 달랐던 답 하나:
- 발표에 인용할 만한 한마디(그대로 받아 적기):

## 발표 자료에 정리하는 법

- 1·2번 설문 답은 표로 모은다(사람 수가 2~3명이라 "3명 중 2명"처럼 쓰고, %는 쓰지 않는다)
- 덜 받은 적이 없는 사람의 답도 쓸모 있다: "확인해 본 적이 없다"(8번)나 "기록이 없어서 넘어갈 것 같다"(12번)는 답이 바로 이 앱이 필요한 이유다
- 4·5번은 인용 한두 줄과 "그래서 무엇을 고쳤다/고칠 계획이다"로 잇는다
- "정식 조사가 아니라 주변 친구 N명에게 물은 것"이라고 꼭 적는다

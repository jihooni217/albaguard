# [양식2] SW 아이템 기획 및 가치 제안서 — 4조

작성일 2026.9.29 · v1.0

> 못 받은 알바비, 기록으로 찾는 앱

## 1. 아이디어 개발

### 1.1 문제 정의

**타겟 고객**
주 15시간 이상 일하는 만 19~26세 시급제 아르바이트 대학생. 근로계약서를 쓰지 않았거나 사본이 없는 경우가 많고, 급여가 입금되면 총액만 확인할 뿐 주휴수당·야간수당이 반영됐는지 따져보지 않으며, 점주에게 정산 문제를 꺼내기 부담스러워함

**기존의 문제점**
1. 얼마를 받아야 하는지 확인할 방법이 없음 — 급여 계산 앱이 있어도 주휴수당 지급 기준이 헷갈려 그냥 믿고 받는 경우가 많고, 덜 받아도 덜 받은 줄 모름 (노동절 근무 알바생 중 "수당을 받는지 안내받지 못해 모르겠다" 33.2%, 알바천국 2026.4)
2. 문제를 알아도 증명할 수단이 없고, 말을 꺼내기도 어려움 — 계약서·출퇴근 기록이 없어 근거가 없고, 관계와 불이익이 걱정돼 문제 제기를 미룸 (최저시급 미달 경험자 중 49.3%가 아무 대응도 하지 않음, 알바천국 2026.6)

**기존 대안의 한계**
알바천국·알바몬·하우머치·기그 등 급여 계산 기능은 이미 여러 곳에서 제공하고 있음. 그러나 구인구직 사이트의 계산기는 근무 기록이 남지 않고, 기그는 사장과 연결해야 출퇴근 기록·전자 근로계약서 등 핵심 기능이 작동하며, 하우머치는 혼자 기록할 수 있지만 예상 급여를 보여주는 데서 멈춤. 네 서비스 모두 실제 입금액과 비교하거나 덜 받았을 때 대응하는 기능은 없음. 진정서 작성 서비스(진정24·노동포털)는 이용자가 이미 증거를 갖추고 있다는 전제하에 시작함.

### 1.2 SW 해결책 및 핵심 기능

**해결방안 Concept**
예상 급여를 계산하는 데서 멈추는 기존 앱과 달리, 근무 기록을 근거로 실제 입금액과 비교해 차액을 찾고 사장에게 보낼 정산 요청 문구까지 만들어주는 앱. 신고 창구를 새로 만드는 것이 아니라 신고 이전 단계(기록 → 비교 → 요청)를 채움

**핵심 기능 (Top 3)**
1. 수정 이력이 남는 근무 기록 — 알바생 혼자 버튼 하나로 출퇴근을 기록하고, 대타나 시간 연장이 생기면 캘린더에 표시해 예정 스케줄과 실제 근무를 비교함. 기록을 고치면 수정 전·후 시각과 수정 사유가 함께 남아, 나중에 지어낸 기록이 아님을 보여줄 수 있음
2. 입금액 비교 및 차액 알림 — 근무 기록으로 계산한 예상 급여(주휴·야간수당 포함)와 실제 입금액을 비교해 차액을 표시
3. 단계별 정산 요청 — 차액과 근거를 담은 요청 메시지 생성 → 내용증명 초안 → 진정 절차 안내 순으로 대응 지원

## 2. 가치 제안 문장

"시급제 아르바이트 대학생을 위한 우리의 알바가드는 급여 계산 앱과 진정서 작성 서비스와 달리 실제 입금액과의 비교, 그리고 근무 기록을 근거로 한 정산 요청 문구 생성을 통해 덜 받아도 모르고, 알아도 말하지 못하는 문제를 해결하고 사장님께 말을 꺼낼 수 있는 근거와 요청 메시지를 제공합니다."

## 3. 차별성 및 검증 계획

**경쟁사 대비 차별화 포인트**
- 기그·하우머치는 사장과 함께 쓰거나 계산에서 끝나고, 진정24는 증거가 있는 사람만 쓸 수 있음. 알바가드는 그 사이의 "혼자 기록 → 차액 발견 → 요청" 단계를 이어줌
- 기록 수정 이력 보존으로 나중에 지어낸 기록이 아님을 보여줄 수 있음
- 바로 신고로 가지 않고 대화로 먼저 해결을 시도하는 정산 요청 문구부터 시작하는 단계적 대응

**핵심 가치 가설**
"알바생은 자신의 근무 기록을 근거로 한 정산 요청 문구가 제공되면, 사장에게 말을 꺼낼 수 있다고 느끼고 기꺼이 사용할 것이다."

**검증 계획**
- 인터뷰 대상: 주변 시급제 알바 대학생 10~15명 (주 15시간 이상 근무자 우선)
- 질문: ① 근로계약서 작성 여부 ② 주휴수당 개념 인지 여부 ③ 덜 받은 경험과 그때 대응 ④ 사장에게 정산 요청을 하지 못했다면 그 이유 ⑤ 기록과 계산 근거가 있으면 사장에게 말할 수 있을지
- 테스트: 시연용 앱으로 출퇴근 기록 → 차액 확인 → 요청 문구 생성까지 직접 써보게 하고, 생성된 문구를 실제로 보낼 의향이 있는지 확인
- 기존 앱 비교: 상세페이지 확인 결과 기그는 사장 연결이 필요하고 하우머치는 혼자 사용 가능함. 두 앱을 직접 설치해 실제 입금액 대조나 체불 대응 기능이 있는지 추가 확인

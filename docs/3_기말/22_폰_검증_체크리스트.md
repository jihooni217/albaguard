# 실제 폰 검증 체크리스트 (아이폰, 약 15분)

기말 보고서 3.4 표를 채우기 위한 것. 위에서부터 순서대로 누르고, 줄마다 됨 / 안 됨 / 이상한 점만 적으면 된다.

- 앱 주소: https://jihooni217.github.io/albaguard/
- **홈 화면에 추가한 앱**으로 열어서 한다(Safari 탭과 홈 화면 앱은 기록이 따로 저장됨)
- 폰에 실제로 쓰던 기록이 있으면 시작 전에 설정 → "백업 파일 만들기"를 한 번 해 둔다
- 시험하면서 남긴 기록은 끝나고 지워도 된다(삭제 사유에 "테스트". 지워도 "삭제됨"으로 흔적은 남는다)
- 검증한 날짜: ____  폰 기종 · iOS 버전: ____

## 1. 기록 등록

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 설정 탭 → 기록 등록의 "N건 등록됨" 숫자를 본다 | 시작 숫자를 적어 둔다 | |
| 근무 기록 탭 → 출근 → 바로 퇴근 | 내역에 기록 한 줄이 생긴다 | |
| 설정 탭으로 가서 숫자를 다시 본다 | 2건 늘어 있다(출근 1 + 퇴근 1). "보내는 중"이 남아 있지 않다 | |
| 방금 기록을 눌러 시각을 고친다(사유 입력) | 사유 없이는 저장이 안 된다. 저장 뒤 설정의 숫자가 1건 더 늘어난다 | |

## 2. 급여 비교와 사진

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 급여 비교 탭 → 받은 금액을 아무 숫자로 넣고 비교하기 | 덜 받은 돈(또는 차액)이 나온다 | |
| 같은 화면 → 증빙 사진 → 사진 찍기 / 고르기 | 카메라나 사진 보관함이 열리고, 붙인 사진이 목록에 보인다 | |

## 3. 증빙 묶음 PDF

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 급여 비교 → 증빙 묶음 PDF 만들기 | 문서가 열린다. 7번 "기록 등록 확인" 표에 방금 기록의 확인 번호와 등록 시각이 있다 | |
| 인쇄 / 저장 버튼 → PDF로 저장(공유 → 파일에 저장) | 파일 앱에서 PDF가 열린다. 사진과 표가 잘리지 않는다 | |

## 4. 정산 요청 보내기

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 정산 요청 탭 → 메시지 만들기 | "짧게 묻기"가 골라져 있고 짧은 문구가 나온다 | |
| 글상자를 눌러 글자를 고친다 | 고쳐진다. 키보드가 버튼을 가리지 않는다 | |
| "메시지 앱으로 보내기" | 공유 창이 뜬다. 카카오톡 · 메시지가 보인다(보내지 않고 닫아도 됨) | |
| "복사하기" → 메모 앱에 붙여 넣기 | 문구가 그대로 붙는다 | |

정산 요청 탭은 덜 받은 달이 있어야 보인다. 2번에서 받은 금액을 받았어야 할 돈보다 적게 넣으면 된다.

## 5. 백업과 맞춰 보기

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 설정 → 백업 파일 만들기 | 공유 창이나 저장 창이 뜬다. 파일 앱에 `알바가드_백업_날짜.json`이 생긴다 | |
| 설정 → 내 기록 맞춰 보기 | 확인 페이지가 열린다 | |
| 확인 페이지 → 백업 파일 고르기 | "기록 N건 중 M건이 등록된 내용과 같습니다". 방금 남긴 기록이 "같음"으로 나온다 | |
| 증빙 묶음 7번의 확인 번호를 확인 페이지 위 칸에 넣기 | 서버 등록 시각이 나온다 | |

## 6. 인터넷 없이

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 비행기 모드를 켜고 앱을 완전히 닫았다가 다시 연다 | 앱이 열리고 기록이 그대로 보인다 | |
| 그 상태에서 출근 → 퇴근 | 기록이 남는다. 설정에 "보내는 중"이 보인다 | |
| 비행기 모드를 끄고 30초쯤 기다린다 | "보내는 중"이 사라지고 등록 건수가 늘어난다 | |

## 7. 백업 파일에서 불러오기 (선택)

지금 기록이 백업 파일 내용으로 바뀌므로, 5번에서 방금 만든 파일로만 해 본다.

| 할 일 | 볼 것 | 결과 |
|---|---|---|
| 설정 → 백업 파일에서 불러오기 → 방금 만든 파일 | 기록과 사진이 그대로 돌아온다 | |

- 안 된 줄, 이상했던 화면은 캡처해 둔다
- 결과를 알려 주면 기말 보고서 3.4 표와 기능별 상태를 채운다
- 갤럭시에서 할 때도 같은 순서. 다른 점은 설치 메뉴 이름과 PDF 저장 창뿐이다

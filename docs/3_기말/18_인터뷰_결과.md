# 인터뷰 결과 (팀원 진행, 카톡)

- 받은 날: 2026.11.17 (팀원이 카톡으로 질문하고 받은 답의 캡처 3장)
- 대상: 팀원 지인 3명(A, B, C). 이름은 가렸다
- 방식: 카톡으로 질문 7개를 하나씩 보내고 짧게 답을 받음. 앱을 직접 써 보게 하지는 않았다
- 더 받는 대로 이 파일에 이어 적는다

## 질문과 답

| 질문 | A | B | C |
|---|---|---|---|
| 1. 알바 중인지 | 예전에 해 봄 | 예전에 4개월, 4시간씩 | 지금 하는 중, 8시간 |
| 2. 월급 확인 방법 | "통장에 꽂히는 것만 확인" | "알람으로 확인" | "확인을 잘 안 함" |
| 3. 가장 쓸모 있어 보이는 기능 | 사장님에게 보내기 | 자동으로 계산되는 기능 | 급여 비교 |
| 4. 정산 요청 메시지를 실제로 보낼지 | "조금 수정해서 보낼 것 같다" | "보낼 수는 없을 것 같다" | "보낼 수 있을 것 같다" |
| 5. 받은 금액을 매달 넣을지 | "조금 귀찮을 것 같다" | "귀찮아도 손해를 안 보려면 하는 게 이득" | "손해를 보기보다는 하는 게 더 좋아 보인다" |
| 6. 게임 화면에만 광고 | "안 좋을 것 같다" | "유저들이 싫어할 것 같다" | "괜찮을 것 같다" |
| 7. 기록 등록(서버에 남는 시각) 설명이 필요한지 | "필요할 것 같다" | "필요해 보인다" | "괜찮을 것 같다" |

따옴표 안은 받은 답을 거의 그대로 옮긴 것(맞춤법만 고침).

## 가설별로 본 것

- **급여를 꼼꼼히 확인하지 않는다**: 3명 모두 그렇다(통장 입금만, 알림만, 잘 안 봄). 설문 "통장 총액만 확인 13명 중 8명"과 같은 방향
- **받은 금액을 매달 넣는다 (중간 보고서 가설 1)**: 2명(B·C)이 넣겠다는 쪽이고 "손해를 안 보려면"이라는 이유를 댔다. A는 "조금 귀찮을 것 같다"고만 답했다(넣겠다는 말은 없음). 설문의 "귀찮지만 할 것 같다 9명"과 비슷한 방향
- **요청 메시지를 실제로 보낸다**: 3명 중 2명이 보내겠다(1명은 고쳐서). 1명은 "보낼 수 없을 것"이라 했다(이유는 묻지 않음, 관계 걱정 T3과 이어질 수 있음). 설문에서는 요청 메시지를 가장 쓸모 있다고 꼽은 사람이 1명뿐이었는데, 여기서는 A가 1순위로 꼽았다
- **게임 화면 광고는 받아들여진다**: 3명 중 2명이 부정적. 설문(싫다 15명 중 5명)보다 반응이 나쁘다. 11/23 광고 실험·게임 유지 판단에 참고
- **기록 등록(확인 번호)은 설명이 있어야 이해된다**: 3명 중 2명이 설명이 필요하다고 함. 앱 안 설명을 쉽게 고칠 근거

## 읽을 때 주의할 점

- 지인 3명, 카톡 짧은 답이라 인터뷰라기보다 짧은 질의응답에 가깝다. 사람 수로만 적고 %는 쓰지 않는다. 숫자보다 인용으로 쓴다
- 7번은 "설명이 필요하나요?"로 물어 "필요하다" 쪽으로 기울기 쉬운 질문이다. C의 "괜찮을 것 같다"가 설명이 필요 없다는 뜻인지, 있으면 괜찮다는 뜻인지 분명하지 않다
- C의 "8시간"이 하루인지 주인지 분명하지 않다(주 8시간이면 주휴수당 대상인 주 15시간에 못 미침)
- B가 4번에서 "보낼 수 없다"고 한 이유는 묻지 않았다. 다음 인터뷰에서는 이유를 한 번 더 묻는다

## 기말 보고서에 넣을 곳 (16 PEST · 17 SWOT은 제출 끝, 고치지 않음)

- **검증 결과 장**: 위 표를 설문 결과와 나란히. "설문 = 숫자, 인터뷰 = 인용"으로 나눠 보여 준다
- **SWOT 전략 갱신**(기말 보고서 안에서 다시 쓸 때)
  - S1+O3 확인 항목("매달 넣겠다" 응답이 유지되는지): 인터뷰 2명 넣겠다("손해를 안 보려면"), 1명 "조금 귀찮을 것"
  - S2+T3 확인 항목("이 문구라면 보내 보겠다"): 3명 중 2명이 보내겠다(1명은 고쳐서)
  - W3+O4 게임 유지 여부: 광고에 2명 부정. 광고 실험 결과와 함께 판단
  - W4 차별점 반응이 약함: 기록 등록은 설명이 필요하다 2명 → 앱 설명 보강을 전략에 넣는다
- **앞으로 고칠 것 후보**(결정은 사용자): 확인 번호 설명 쉽게, 요청 메시지를 고쳐 쓰기 쉽게(이미 화면에서 고칠 수 있음을 더 잘 보이게)

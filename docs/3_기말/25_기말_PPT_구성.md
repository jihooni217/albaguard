# 기말 발표 PPT 구성 (초안, 2026.11.27)

교수님 기말 안내가 없어 중간 때처럼 **발표 15~20분 + 질의응답**으로 잡는다. 디자인은 중간 발표·SWOT 결과·포지셔닝 맵과 같은 "통장 원장"(흰 종이, 잉크 남색, 줄과 구분선, 맑은 고딕). 12/1에 이 구성으로 만든다.

## 이야기 줄기

중간: "먼저 만들어 봤다" → 기말: **"써 볼 사람에게 물어봤고, 그래서 바꿨다"**

- 맨 앞과 맨 뒤에 같은 한 줄: 통장 총액만 보는 사람이 많다(설문 알바 경험자 13명 중 8명) → 그래서 "받은 돈과 비교"를 앞세웠다
- 약점(게임 반응, 기록 등록 0명, 표본이 적음)은 숨기지 않고 "그래서 바꾼 것"과 짝지어 말한다

- 손유호 몫: 3·4장(숫자를 읽으면 되는 장, 약 3분). 대본은 한 장에 4~5문장으로 짧게, 숫자는 화면에 크게
- 질의응답은 이지훈. 예상 질문은 `15_기말_예상_질문.md`에 이어서 모음
- 빼 둔 것(부록 장으로만, 질문 나오면 넘김): SWOT 12개 전략, PEST 표, 4P 표, 위치마다 근거, 설문 문항 전체

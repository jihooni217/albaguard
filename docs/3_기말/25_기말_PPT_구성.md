# 기말 발표 PPT 구성 (초안, 2026.11.27, 같은 날 스킬 점검 반영)

교수님 기말 안내가 없어 중간 때처럼 **발표 15~20분 + 질의응답**으로 잡는다. 디자인은 중간 발표·SWOT 결과·포지셔닝 맵과 같은 "통장 원장"(흰 종이, 잉크 남색, 줄과 구분선, 맑은 고딕). 12/1에 이 구성으로 만든다.

## 이야기 줄기

중간: "먼저 만들어 봤다" → 기말: **"써 볼 사람에게 물어봤고, 그래서 바꿨다"**

- 맨 앞과 맨 뒤에 같은 한 줄: 통장 총액만 보는 사람이 많다(설문 알바 경험자 13명 중 8명) → 그래서 "받은 돈과 비교"를 앞세웠다
- 약한 결과(게임 반응, 기록 등록 0명)는 "그래서 바꾼 것"과 짝지어 말한다
- **교수님 기준(DAP2 피드백 11/26)**: "미실시·안 함·못했습니다"는 감점. 화면과 대본 모두 한 일은 "했다", 아직인 일은 "다음 단계", 일부러 고른 것은 "대신 ~를 택함"으로. 학과는 "전공". 글꼴은 맑은 고딕 하나(표 포함)
